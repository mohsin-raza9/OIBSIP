# Oasis Infobyte Internship Projects

This repository contains my Python Programming projects completed as part of the **Oasis Infobyte Internship (OIBSIP)**.

The projects demonstrate practical Python programming skills, GUI development, database integration, input validation, and client-server communication.

## Projects

### 1. BMI Calculator

A graphical BMI Calculator built with Python and Tkinter.

**Features:**
- Calculate Body Mass Index (BMI).
- Classify results into Underweight, Normal, Overweight, and Obese.
- Input validation and error handling.
- Support for multiple users.
- Store BMI records using SQLite.
- View previous calculation history.
- Visualize BMI trends using Matplotlib.

**Technologies:** Python, Tkinter, SQLite, Matplotlib

### 2. Random Password Generator

A Python-based application for generating secure random passwords.

**Features:**
- Generate random passwords.
- Customize password generation options.
- Support for strong password creation.
- Clipboard functionality.
- Password history management.

**Technologies:** Python

### 3. Chat Application

A client-server chat application developed using Python.

**Features:**
- Client-server communication.
- Multiple chat rooms.
- Room-based message separation.
- Real-time message exchange.
- SQLite database integration.
- Separate chat history for different rooms.

**Technologies:** Python, Socket Programming, SQLite
